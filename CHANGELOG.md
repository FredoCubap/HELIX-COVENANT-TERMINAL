# Changelog

Todos los cambios relevantes de este proyecto se documentan en este fichero.

El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y el proyecto usa [SemVer](https://semver.org/lang/es/).

## [Unreleased]

### Added

- Ventana principal aislada, contrato IPC validado y pruebas locales de seguridad.
- Licencia Apache-2.0 y archivo `NOTICE` con la atribución a FredoCubap.
- Specs de OpenSpec de los changes `bootstrap-app-shell` y `terminal-core`.
- Flujo de contribución (`CONTRIBUTING.md`) y plantilla de PR.

### Changed

- Se quita el menú de aplicación de Electron: `Ctrl+R`, `Ctrl+W` y `Ctrl+Shift+I` ya no recargan, cierran la ventana ni abren DevTools.
